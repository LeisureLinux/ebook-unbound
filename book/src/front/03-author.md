# 作者简介 {.unnumbered}

LeisureLinux，B 站频道与微信公众号同名。长期做企业 IT 基础设施与基础架构，从 Unix 主机、数据库与数据中心运维，一路做到跨国团队的 IT 负责人与上市公司 CIO；近年的重心转向开源自建、家庭网关、DNS 与网络链的自主可控。

与这本书直接相关的一段经历，是在大规模企业环境里长期负责「名字与地址」这一层：

- 负责过跨地域数据中心的 7×24 基础架构运营，涉及高可用集群、容灾、容量规划与事件响应，也管过把数据中心整体迁移到另一地区的项目。那段时间最深的体会是：**故障往往不在某一台服务器，而在解析器、路由、缓存与人的排查顺序交界处**。
- 主导过大型企业办公网络与园区网络的基础架构，包含广域网线路、负载均衡、SSL VPN、企业无线、以及 DDI（DNS / DHCP / IP 地址管理）平台的选型与替换。DDI 这类系统平时没人注意，一旦解析不对，全公司都上不了网。
- 长期维护 Unix / Linux、虚拟化与私有云环境（Solaris / AIX / Linux、VMware、Proxmox / KVM），也做过基于 WireGuard 的企业远程接入、多云备份与边缘网关。
- 写过面向 IT 服务的自动化与观测平台：资产自动发现、CMDB、监控与报表，以及把事件流程、升级路径和 SLA 固化下来的运营体系。

技术写作之外，也做内容运营：B 站与微信公众号 *LeisureLinux* 主要聊 Linux、开源自建、家庭网络与 DNS。
